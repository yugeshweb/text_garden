# Text Garden

A little type toy where flowers grow out of your words.

Start typing and stems, leaves and flowers sprout from each letter. Move your mouse around and the garden leans toward it. Click anywhere and a butterfly comes to visit.

## How to use

- **Type** to grow
- **Space** cuts the stem, so the next word starts a new garden
- **Backspace** withers the last letter
- **Enter** clears everything
- **Double click** to plant a single flower
- **Ctrl/Cmd + S** saves a PNG, add Shift for an SVG

Pick a flower in the top left: rose, tulip, daisy, poppy, or mixed. There are ten color palettes along the bottom.

## Poster mode

Switch to Poster to turn a word into a 1080 x 1080 looping animation. Choose a motion (breathe, grow and wither, typed, gust, reach, scatter, visitor), a flower and a palette, then export it as a video or a zip of PNG frames.

## Running it

It's a single HTML file with no build step. Just open `index.html` in a browser.

Everything is drawn on a canvas with plain JavaScript. Fonts are Playfair Display and DM Mono from Google Fonts.
